WHAT CHANGED
- Rooms have Map view / Show chat. Map view uses the window's full map area while
  preserving the complete map and original aspect ratio. Escape brings chat back.
  The last view preference is remembered in this browser.
- Normal desktop room view uses a slightly narrower chat column to free map width.
- Taskbar, active app buttons, Start button, clock tray, and fonts use the existing
  global Appearance palette. Start is now native text so it can use the selected font.
- The gear beside the clock opens Appearance directly.
- Appearance now includes color wells, editable hex, HSL sliders, live preview,
  Save colors, and Revert preview. These are the same colors saved by MyPixel.
- A style-only API saves palette changes without replacing profile text or avatars.
  No database migration is required. Server and browser files must deploy together.

Map view keeps the entire artwork visible. Some empty space is unavoidable whenever
the window and image have different proportions; filling that space would require
cropping or distortion. This update does neither.
