# MyPixel profiles

MyPixel profiles belong to existing 8BitGPU accounts. Open MyPixel, choose Edit My Page, and set your mood, About Me, favorite things, independent colors, and images.

Each of the six colors has a full-spectrum picker and separate hue, saturation, and lightness sliders. Changing one part does not change the others.

Upload files for three framed pictures and a page wallpaper. These uploads save immediately and are public on your profile. Text and color edits save with Save My Page. See MYPIXEL-CUSTOMIZATION.md for formats, limits, and deployment notes.

The public address is 8bitgpu.net/~CreatureName. Clicking a Being in the lounge opens that profile.

Deploy frontend files, profile-assets, and src/worker.js together, using the existing Worker/D1 configuration. Existing profiles are preserved, and the image table is created automatically. Connections, guestbooks, and server-backed collection badges remain future features.
